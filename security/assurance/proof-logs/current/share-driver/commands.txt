# Exact heavy commands (run inside the task worktree)

All heavy commands go through the global lock/wrapper:
`~/.local/opt/vela-tools/bin/vela-heavy`

Common normal-cargo target:
`CARGO_TARGET_DIR=/home/hirew/.t3/worktrees/VELA/t3-700776df/target`

Common hax/F* environment:
```
CARGO_HOME=/tmp/vela-hax-cargo
OPAMROOT=$HOME/.local/opt/vela-tools/opam
PATH=/tmp/vela-fstar-prebuilt/fstar/bin:$HOME/.local/opt/vela-tools/bin:$HOME/.local/opt/vela-tools/opam/vela-hax/bin:$PATH
```

The shared target directory is also used by other worktrees, so a `cargo
clean -p vela-share-policy` is run immediately before each normal-cargo test
group. Otherwise a concurrent hax build from another worktree can leave a
stale `vela_share_policy` rlib that does not contain the new `driver` module.

## Historical + focused proof

```
cd serverVELA/vela-share-policy
export CARGO_HOME=... OPAMROOT=... PATH=... CARGO_TARGET_DIR=... CARGO_PROFILE_DEV_CODEGEN_BACKEND=llvm
~/.local/opt/vela-tools/bin/vela-heavy ./verify-fstar.sh
# -> fstar-full-verify.log
```

`verify-fstar.sh` first runs `cargo test`, re-extracts the historical 23
selected functions into `proofs/fstar/extraction/`, checks them with F*, then
calls `verify-fstar-driver.sh`, which:

```
rm -rf proofs/fstar/extraction-driver
cargo hax into --output-dir proofs/fstar/extraction-driver \
  -i '-** +vela_share_policy::driver::begin_send \
       +vela_share_policy::driver::begin_link_update \
       +vela_share_policy::driver::begin_link_revoke \
       +vela_share_policy::driver::begin_inbox_delete \
       +vela_share_policy::driver::begin_ek_registration \
       +vela_share_policy::driver::step \
       +vela_share_policy::driver::on_link_observation \
       +vela_share_policy::driver::on_ek_observation \
       +vela_share_policy::driver::on_send_completed \
       +vela_share_policy::driver::on_rows_observed \
       +vela_share_policy::driver::on_cleanup_completed' \
  fstar --z3rlimit 500
# textual proof-escape guard (no assume/admit/--lax)
fstar.exe --cmi --cache_off --warn_error -331 --z3rlimit 4000 \
  --z3version 4.13.3 \
  --already_cached '+Prims+FStar+LowStar+C+Spec.Loops+TestLib' \
  --include "$hax_lib_root/proof-libs/fstar/core" \
  --include "$hax_lib_root/proof-libs/fstar/rust_primitives" \
  --include "$hax_lib_root/proofs/fstar/extraction" \
  --include proofs/fstar/extraction-driver \
  --include proofs/fstar/driver-lemmas \
  --include proofs/fstar/driver-composition \
  proofs/fstar/extraction-driver/Vela_share_policy.Driver.fst \
  proofs/fstar/extraction-driver/Vela_share_policy.fst \
  proofs/fstar/driver-lemmas/Vela_share_policy_driver_lemmas.fst \
  proofs/fstar/driver-composition/Vela_share_policy_driver_composition.fst
```

The exact F* argv is printed in `fstar-full-verify.log`.
