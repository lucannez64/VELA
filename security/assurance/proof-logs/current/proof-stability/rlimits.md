## Method

- Shell rows: every tracked `*.sh` file, one row per `--z3rlimit`/`--z3rlimit=` occurrence, with the whole line as the setting text.
- F* rows: every tracked `*.fst`/`*.fsti` outside `proof-logs/`, one row per line that mentions `--z3rlimit`, tagged with its directive.
- `--z3seed`: same F* scan; none is expected because the seed shim would not be able to override a module's own setting.
- `--query_stats`: F* 2025.10.06 prints one line per query with the configured limit and the fraction it used; this script keeps the maximum per module.
