## Historical + focused proof

```
cd serverVELA/vela-session-policy
export CARGO_HOME=... OPAMROOT=... PATH=... CARGO_TARGET_DIR=...
~/.local/opt/vela-tools/bin/vela-heavy ./verify-fstar.sh
# -> fstar-full-verify.log
```

`verify-fstar.sh` first tests the crate, re-extracts the historical 21
selected functions into `proofs/fstar/extraction/`, checks them with F*, then
calls `verify-fstar-login-driver.sh`, which:

```
rm -rf proofs/fstar/extraction-login-driver
cargo hax into --output-dir proofs/fstar/extraction-login-driver \
  -i '-** +vela_session_policy::challenge::purpose_stored_tag \
       +vela_session_policy::challenge::classify_stored_tag \
       +vela_session_policy::challenge::classify_consumption \
       +vela_session_policy::login_driver::begin_login \
       +vela_session_policy::login_driver::step \
       +vela_session_policy::login_driver::on_challenge_taken \
       +vela_session_policy::login_driver::on_device_looked_up \
       +vela_session_policy::login_driver::on_verifier_finished \
       +vela_session_policy::login_driver::on_failure_record_observed \
       +vela_session_policy::login_driver::on_backoff_reset_observed_event \
       +vela_session_policy::login_driver::on_token_issue_observed \
       +vela_session_policy::login_driver::on_token_track_observed' \
  fstar --z3rlimit 500
# textual proof-escape guard (no assume/admit/axiom/--lax)
fstar.exe --cmi --cache_off --warn_error -331 --z3rlimit 16000 \
  --z3version 4.13.3 \
  --already_cached '+Prims+FStar+LowStar+C+Spec.Loops+TestLib' \
  --include "$hax_lib_root/proof-libs/fstar/core" \
  --include "$hax_lib_root/proof-libs/fstar/rust_primitives" \
  --include "$hax_lib_root/proofs/fstar/extraction" \
  --include proofs/fstar/extraction-login-driver \
  --include proofs/fstar/challenge-lemmas \
  --include proofs/fstar/login-driver-lemmas \
  proofs/fstar/extraction-login-driver/Vela_session_policy.Challenge.fst \
  proofs/fstar/extraction-login-driver/Vela_session_policy.Login_driver.fst \
  proofs/fstar/challenge-lemmas/Vela_session_policy_challenge_lemmas.fst \
  proofs/fstar/login-driver-lemmas/Vela_session_policy_login_driver_lemmas.fst
```

## Mutation checks

Both mutate a **copy** of the extracted driver in `/tmp/opencode`, never the
production source. The command is the focused F* invocation above with
`--include /tmp/opencode/mutant-purpose` (or `mutant-verifier`) replacing the
focused extraction include.

- `mutant-purpose`: in `on_challenge_observed`, the `WrongPurpose` branch is
  changed to the `Accepted` transition (`Device` + `challenge_accepted = true`).
  The focused check fails at
  `Vela_session_policy_login_driver_lemmas.step_challenge_flag_origin`
  (`mutation-drop-purpose-check.log`).
- `mutant-verifier`: in `on_verifier_observed`, the `RejectedUnauthorized`
  branch is changed to the `Valid` transition (`Reset` + `verifier_valid =
  true`). The focused check fails at
  `Vela_session_policy_login_driver_lemmas.step_verifier_flag_origin`
  (`mutation-drop-verifier-gate.log`).
