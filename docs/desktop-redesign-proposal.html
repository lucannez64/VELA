Additional fields & websites

Optional fields appear when needed. The native implementation will support typed custom fields, additional URLs, and address sections here.

01 · Scan, then inspect

59px rows replace large separated cards. Credentials and copy actions stay in the detail pane. No empty alphabet sections.

02 · One place for organization

Folders and tags live in labeled navigation. On narrow windows, a drawer keeps the same structure.

03 · Adapt the workflow

Three panes when space allows. A list and back navigation on narrow windows. Editing uses a focused side sheet.

Reversible by design: this is a standalone proposal, with no vault access or app changes. Native rollout would use an opt-in --experimental-vault-ui switch with the existing view as the default.
Reference direction: Dribbble · password management · Shakuro · product work. Mobbin’s detailed app flows require login and were not inspected. Original layout and components; no copied assets.
